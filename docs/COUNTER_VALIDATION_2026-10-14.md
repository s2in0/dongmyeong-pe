# JUMPY 낮은 점프·번갈아뛰기 검증

검증일: 2026-10-14. 웹앱의 학생 측정 카운터를 수정했습니다. Apps Script·시트 저장 형식·디자인 가이드는 변경하지 않았습니다.

## 재현된 문제

기존 웹앱은 발목 두 개의 평균 높이를 주 신호로 쓰고, 양발 모두 몸통 길이의 3% 이상 함께 상승해야 인정했습니다. 번갈아뛰기는 올라가는 발과 내려가는 발이 상쇄되며 이 조건에서 거부됩니다. 낮은 점프에는 높이 문턱과 신호 평활화도 불리했습니다. 포즈 전체의 가시성이 매 프레임 0.7 이상이어야 해서 움직이는 발의 일시적인 신뢰도 저하 때 프레임을 버렸습니다.

기존 합성 테스트는 기본 Python 이식 설정을 검증했으며, 웹앱이 실제로 선택한 `source:'feet', requireFeet:true, rhythmMin:1` 조합을 그대로 검증하지 않았습니다. 이번에는 웹앱과 검증 도구가 같은 `createClassroomCounter`와 `measurementSignal`을 사용합니다.

## 변경

- 몸통의 상승·하강을 주 신호로 쓰고, 머리·엉덩이의 일관된 상승과 눈에 보이는 발의 움직임을 함께 확인합니다.
- 양발 동시 상승 대신 움직이는 발의 상승을 허용해 복서 스텝과 번갈아뛰기를 처리합니다. 발을 못 보거나 몸이 올라가지 않은 무릎 들기는 인정하지 않습니다.
- 보통 민감도의 높이 문턱을 0.05에서 0.012로 줄이고, 발 보조 문턱도 줄였습니다. `낮음 / 보통 / 높음`은 각각 0.020 / 0.012 / 0.008입니다.
- 연속 3회에서 리듬을 확인하면 앞의 기록도 함께 반영합니다. 잠깐 검출이 빠졌다고 해서 빠진 횟수를 만들어 더하지 않습니다.
- 걷기 오인식을 막기 위해 수평 이동을 더 엄격하게 검사합니다. 카메라가 멈췄다가 재개되면 예전 상승 상태를 이어 붙이지 않습니다.
- 캔버스 크기를 매 프레임 초기화하던 작업을 제거했습니다.

## 공개 영상 재생 검증

원본 영상의 발·줄 동작을 프레임별로 보고 횟수를 표시했습니다. 알고리즘의 검출 피크를 정답으로 사용하지 않았습니다. 원본에 포함된 느린 재생 구간은 그 속도를 유지했습니다. 영상 끝의 이미 진행 중인 점프와 장면 전환 구간은 표의 시간 범위로 제한했습니다.

웹앱과 동일한 **MediaPipe lite 모델 / Tasks 1.0.1**로 CPU 포즈를 추론하고, 동일한 포즈를 수정 전·후 JavaScript 카운터에 넣었습니다. 추론 긴 변은 최대 720픽셀이고, 민감도는 보통입니다. 이전 코드는 `f0ba23cc543b779887262110cba7d252b3a6b4dd`입니다.

## 실제 브라우저의 영상 추론도 확인

Edge 브라우저에서 영상 파일 자체를 읽고 웹용 `detectForVideo`를 CPU로 실행했습니다. 캐시된 Python 포즈를 재사용하지 않았습니다.

**39회 중 38회**를 잡았습니다. 같은 모델이어도 영상 크기, 런타임의 전처리·포즈 추론, 프레임 간격에 따라 결과가 다릅니다. 실제 아이패드의 GPU·조명·카메라 거리·프레임 손실과 체육 선생님의 촬영본은 이번 검사에 포함하지 못했습니다.

## 재검증

```text
node docs/test_counter.js
node docs/test_classroom_counter.cjs
node docs/test_video_counter.cjs
node tools/evaluate_web_counter.cjs --baseline /path/to/old/jump_counter.js
```

`docs/fixtures/jump-counter`에는 원본 영상 대신 필요한 관절 좌표, 출처, 시간 범위, 수동 횟수가 들어 있습니다. `tools/extract_web_pose_tracks.py`로 새 영상도 같은 형식으로 추출할 수 있습니다.

합성 회귀 검사는 15·24·30·60 FPS의 낮은 점프와 번갈아뛰기, 발 가시성 저하를 검증합니다. 발을 붙인 무릎 굽히기·어깨 흔들기·무릎만 들기·걷기·작은 추적 잡음·숨겨진 발·카메라 중단은 추가 횟수 없이 통과했습니다. 이는 실제 아이패드 촬영을 대신하는 결과는 아닙니다.

수업에서는 전신과 양발이 보이게 기기를 고정하고 처음 3회가 확인될 때까지 이어서 뛰어 주세요. 먼저 보통 민감도로 실제 20회를 비교하고, 아주 낮은 점프가 빠지면 높음으로 다시 비교하는 것이 좋습니다.
