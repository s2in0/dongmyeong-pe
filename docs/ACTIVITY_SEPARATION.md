# 반별 활동과 저장 탭 분리

같은 스프레드시트에서 1학년 각 반의 줄넘기 기록과 음악줄넘기 제출을 별도 탭에 누적합니다. 기존 자동 생성 반별 요약 탭을 줄넘기 전용 탭으로 이름을 바꾸고, 반별 음악 제출 탭을 하나씩 추가합니다. 날짜마다 새 탭을 만들지 않습니다. 원본 기록, 음악줄넘기, 각 활동 수업이력은 유지합니다.

줄넘기 탭에는 측정일시·번호·횟수·측정시간·당시 줄넘기 설정을 표시합니다. 음악 탭에는 모둠 이름·주제·제출일시·안무·당시 음악 설정·BPM을 표시합니다. 음악 활동이 없는 날에는 제출 행이 추가되지 않습니다.

학생 번호는 1학년 1반과 2반 1~15번, 3반 1~14번입니다. 선생님 줄넘기 화면에 이번 수업의 전체 인원·기록 완료·미완료·기록 없는 번호를 표시합니다. 반복 기록은 인원에서 중복 집계하지 않으며 0회도 완료 기록입니다. 음악줄넘기는 모둠 제출 수만 표시하며 학생별 미완료 인원은 표시하지 않습니다.

기존 자료가 있는 비관리 탭은 덮어쓰지 않습니다. 음악 설정을 바꿔도 줄넘기 기록·순위·재도전 횟수는 초기화하지 않습니다. 원래 두 디자인 가이드 MD는 변경하지 않습니다.
