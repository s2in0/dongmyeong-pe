# 줄넘기와 음악 줄넘기 활동 분리

줄넘기 기록과 순위에는 측정 날짜, 학생 번호, 횟수, 측정 시간, 줄넘기 설정만 표시합니다. 음악 기본 동작과 음악 설정은 새 줄넘기 기록에 저장하지 않습니다. 기존 원본 데이터는 삭제하지 않고 조회 화면에서 제외합니다.

음악 줄넘기는 반별로 활동 열기, 기본 동작, 수업 이력을 따로 관리합니다. 음악 설정과 동작을 바꿔도 줄넘기 재도전 횟수와 순위는 초기화되지 않습니다. 줄넘기를 닫아도 음악 활동을 열 수 있습니다. 학생 음악 제출은 음악 수업 스냅샷만 저장하며 노래 BPM·안무는 해당 음악 활동에 남습니다.

음악수업이력은 하나의 이력 시트에 누적합니다. 날짜마다 새 탭을 만들지 않습니다. 기존 1학년 각 반 요약 시트에는 줄넘기 기록과 음악 활동을 별도 구역으로 표시합니다. 원본 기록 및 기존 음악 제출 데이터는 유지합니다.

검증: test_fast_records.cjs, test_class_sheets.cjs, 음악 리듬·시퀀스·접기 테스트를 통과했습니다. 실제 아이패드 수업의 동시 전송 시간은 별도로 현장에서 확인해야 합니다.
