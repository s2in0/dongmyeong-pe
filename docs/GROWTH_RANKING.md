# 수업 순위와 최고기록 대비 향상

프런트엔드 v43. 기존 Apps Script v19와 연결하며 서버 저장 형식은 바꾸지 않는다.

1. 측정 중: 교사만 받는 임시 횟수로 막대·순서·숫자를 움직인다. 임시 횟수는 제출 완료나 원본 기록에 포함하지 않는다.
2. 등록된 학생이 모두 제출하고 진행 중인 재도전이 없으면 오늘 기록으로 자동 전환한다. 결석 등으로 전원 제출하지 않는 날은 ‘줄넘기 활동 종료’를 누른다. 이 버튼은 줄넘기의 현재 설정을 유지하며 활동 열림만 끈다. 음악 활동은 독립적이다.
3. 종료한 뒤에도 이미 뛰고 있던 학생은 마칠 수 있다. 도착한 확정 기록은 오늘 기록과 비교 목록에 반영된다. 전송 대기 중인 수치는 최종 기록으로 확정하지 않는다.
4. ‘향상 순위 · 성장왕 발표’를 누르면 같은 제한시간의 **오늘 이전 최고기록**과 비교한다. 한국 날짜 기준으로 오늘의 다른 수업·재도전, 미래 날짜, 잘못된 날짜, 다른 제한시간을 기준에서 제외한다. 날짜는 선택한 수업의 마지막 확정 기록을 사용해 다음 날 다시 열어도 기준이 임의로 바뀌지 않는다.
5. 증가 횟수에 따라 3→2→1등을 발표한다. 공동 순위는 유지한다. 이후 전체 향상 순위에서 감소·동일·첫 기록도 확인한다. 첫 기록은 가상의 0회와 비교하지 않는다. 오늘 기록에는 교사가 선택한 마지막/최고 기록 반영 규칙을 표시한다.

순위는 새 수업을 명시적으로 시작하기 전까지 마지막 접수 후 24시간 보존하는 기존 규칙을 따른다. 제출이 모두 끝난 뒤 재도전을 시작하면 다시 실시간 횟수를 표시한다. 반 명부는 1반 15명·2반 15명·3반 14명이다.

검증: 최고기록이 가장 최근 기록보다 높은 경우, 한국 날짜 경계, 동일 날짜 재도전 제외, 시간별 비교, 첫 기록·0회·감소·공동 순위, 실시간→전원 제출→오늘 기록→성장왕→전체 비교 및 교사 종료 후 진행 중 기록의 분리를 검사했다. 화면 검사는 모의 기록으로 수행했다. 음악 코드·원본 학생 기록·디자인 가이드 MD는 수정하지 않았다.
