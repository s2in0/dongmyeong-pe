# 실시간 차트와 성장왕 발표

교사 화면 ‘우리 반 순위’는 측정 중 개수를 약 2초 간격으로 별도 채널에서 받아 막대 너비와 학생 순서를 움직인다. 임시 개수는 ‘측정 중’으로 표시하며 기록 참여 인원·최종 기록·재도전 횟수에 포함하지 않는다. 학생 수에 맞춰 시작 전 번호도 표시한다. 연결이 지연되면 해당 상태를 표시한다. 취소·이전 수업·완료된 측정 ID의 늦은 업데이트가 최종 순위를 덮어쓰지 못하도록 처리한다.

측정 중에는 기존 설정 조회 요청을 중복으로 보내지 않는다. 측정 시작 시 확정한 설정으로 끝까지 진행하며, 완료 후 최신 설정을 다시 조회한다. 최종 기록은 기존 전송 큐에서 별도로 재전송·보존한다. 실시간 개수는 CacheService만 사용하고 원본 시트에 쓰지 않는다. 수업 종료 후 진행 중인 측정의 완료와 마지막 기록 후 24시간 순위 보존은 그대로 유지한다.

‘성장왕 3·2·1등 발표’는 현재 수업에서 확정된 기록과 같은 제한시간으로 측정한 이전 수업의 가장 최근 기록을 비교한다. 현재 수업의 재도전·서로 다른 제한시간은 비교 기준으로 사용하지 않는다. 증가한 횟수 순서로 3등 → 2등 → 1등을 공개하고 공동 순위를 보존한다. 첫 기록은 0회와 비교하지 않으며 성장왕 대상에 넣지 않는다. 증가자가 없으면 안내 후 전체 비교를 제공한다. 발표가 끝나야 ‘전체 향상 순위 보기’가 활성화되고, 이전·이번·증가 횟수 및 첫 기록 학생을 표시한다. 뒤늦게 확정된 최종 기록은 발표 화면과 비교 목록에도 반영한다.

검증: 15명 임시 개수의 시트 없는 처리, 확정 기록과의 분리, 요청 순서 역전·취소·반/시간 검증·교사 종료·완료 기록 우선 처리, 같은 시간의 이전 수업 기준·0회·감소·첫 기록·공동 순위, 브라우저에서 차트 개수 전환·3→2→1 공개·전체 비교 잠금 해제·실시간 화면 복귀를 확인했다. 브라우저 화면 검증은 모의 서버/합성 기록으로 수행했으며 운영 시트에 테스트 학생 기록을 제출하지 않았다.

반별 노래·배속·나뉜 칸·음악 발표 기능은 2026-10-19의 main(a2e5f48)에 있던 구현을 그대로 보존한다. 이전 작업 폴더의 오래된 음악 코드를 덮어쓰지 않는다. 프런트엔드 v41과 갱신한 Apps Script를 함께 배포한다. 디자인 가이드 MD 두 파일과 원본 학생 기록은 수정하지 않는다.
