# 수업 설정 저장 · 2026-10-15

설정 저장은 학생 기록·반별 요약 시트 작업의 잠금을 기다리지 않습니다. 교사 PIN을 검증한 뒤 반별 설정 전체를 `JUMPY_SETTINGS_<학년>_<반>` 스크립트 속성에 한 번 쓰고, 다시 읽은 값과 요청 ID를 응답합니다. 앱의 설정 조회는 이 저장값을 우선 사용합니다. 기존 속성이 없는 반은 기존 `설정` 시트를 읽습니다.

교사 화면은 자동 조회 중에도 저장을 전송하고, 먼저 시작한 조회를 취소해 오래된 설정이 새 설정을 덮어쓰지 않도록 합니다. 저장 요청의 응답만 유실되면 요청 ID를 조회해 완료 여부를 확인합니다. 입력값과 확인값이 일치해야 ‘저장 확인’으로 표시합니다.

교사 화면이 열려 있는 동안 별도 요청으로 반별 시트를 정리합니다. 설정 변경 직후와 이후 약 1분 간격으로 수행하며, 이미 정리 중이면 다음 정리를 예약합니다. 원본 `설정` 시트로의 복사와 수업 스냅샷 확정에는 짧은 기록 잠금을 사용하고, 요약 시트의 서식·전체 이력 갱신에는 별도 잠금을 사용합니다. 요약 지연이 설정 저장 성공을 실패로 바꾸지 않습니다. 교사 화면이 닫혀 있으면 다음 접속·정리 시점에 시트가 갱신됩니다.

학생 홈 화면에서도 5초마다 설정을 조회합니다. 측정 버튼을 누르면 새로 조회한 설정으로 시작하며, 조회가 실패하면 오래된 설정으로 새 측정을 시작하지 않습니다. 진행 중인 측정의 시간은 시작 당시 설정을 유지합니다.

검증: `test_settings_save.cjs`는 기록 잠금이 사용 중일 때의 60초·재도전 해제 저장, 같은 요청 재시도, 반 분리, 시트 복사, 수업 스냅샷 보존, 교사 인증을 검증합니다. 브라우저 테스트는 자동 조회 중 저장 클릭, 이전 조회 응답 무시, 저장 응답 유실 복구, 학생 설정 갱신과 측정 직전 확인을 검증했습니다. 이 브라우저 테스트의 네트워크 응답은 모의이며 실제 15대 아이패드 동시 수업 지연을 측정한 결과는 아닙니다.
