# 테스트

학생: `./?test=1&view=history` / 음악: `./?test=1&view=music` / 교사: `teacher.html?test=1`

- 학생·교사 진입 화면과 교사 반 선택에 ‘테스트’ 링크를 추가했다. 테스트 화면은 PIN 없이 열린다.
- 15명의 가상 기록 142개, 학생별 성장 그래프·달력·메달, 최고기록 대비 향상 순위, 가상곡 3곡과 모둠 3개의 안무를 제공한다. 15번은 첫 기록 학생 예시다.
- 노래는 123·125·128 BPM의 자체 합성 곡이며 실제로 재생된다. 한 칸 8박·한 줄 8칸, 나뉜 칸, 학생 연습·교사 발표 화면을 사용한다.
- 교사 ‘실시간 보기’는 가상 개수 변동을 재생한다. ‘오늘 기록 보기’에서 확정 기록·성장왕 발표를 볼 수 있다.
- 테스트의 요청은 `test_class.js`에서 처리한다. 실제 Apps Script·시트·Drive에는 보내지 않는다. 실반용 API의 PIN 검증을 바꾸지 않았다.
- 테스트 기록·초안·미전송 큐는 `jumpy_test_` 저장 공간을 사용한다. 실제 미전송 큐를 읽거나 전송하지 않는다. 노래 캐시는 별도의 `test-song-` ID를 사용한다.
- 테스트에서 바꾼 내용은 같은 브라우저에서 공유되며, 날짜가 바뀌면 현재 날짜의 예시를 새로 만든다. ‘예시 초기화’는 테스트 저장 공간만 지운다.
- 테스트 QR·복사 링크에도 `test=1`을 보존하고 실제 시트 주소·PIN을 넣지 않는다. ‘실제 수업’ 링크는 일반 진입 화면으로 돌아간다.

검사: `node docs/test_test_class.mjs`, `node docs/test_student_access.mjs`, `node docs/test_pending_records.mjs`. 실제 UI 검사는 학생 그래프, 가상 노래 재생, 15명 순위와 3→2→1 발표, 교사 음악 발표, QR, 실반 저장 공간 보존과 외부 서버 요청 0건을 확인했다. Apps Script와 디자인 가이드 MD는 변경하지 않는다.
